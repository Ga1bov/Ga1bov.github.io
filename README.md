# Gaibov — личный сайт-портфолио

Сайт независимого разработчика: сайты, веб- и мобильные приложения, боты под ключ. Живой адрес: https://ga1bov.github.io/

Статика без сборки и зависимостей: HTML, CSS и немного JavaScript. Два языка (русский и английский), стеклянный интерфейс, три кейса с галереями и форма заявки: бриф уходит владельцу в Telegram.

## Запуск

Откройте `index.html` двойным кликом или поднимите любой статический сервер в этой папке:

```
python -m http.server 8796
```

## Устройство

```
index.html        вся разметка, иконки (inline sprite), три <dialog> с кейсами
css/style.css     токены, стекло, компоненты, адаптив (320–1920 px), prefers-reduced-motion
js/config.js      настройки: Telegram, канал, адрес приёма заявок
js/i18n.js        английский словарь и строки формы
js/main.js        язык, навигация, появление блоков, кейсы, бриф
assets/           шрифт Golos Text, скриншоты работ, favicon, превью для соцсетей
```

Шрифт Golos Text (SIL OFL 1.1) лежит локально: сайт не обращается к сторонним сервисам, кроме отправки заявки.
